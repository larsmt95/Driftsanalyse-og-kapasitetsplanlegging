# Driftsanalyse og kapasitetsplanlegging

## Formål

Undersøke hvordan etterspørsel varierer over tid, og hvordan
sannsynlighetsmodellering kan brukes til å vurdere kapasitetsbehov
og risikoen for kapasitetsproblemer.

## Problemstilling

Hvor stor er sannsynligheten for at etterspørselen overstiger
tilgjengelig kapasitet, og hvordan bør kapasiteten dimensjoneres
for å oppnå et ønsket servicenivå?

## Planlagt arbeidsflyt

1. Hente inn og kvalitetssikre data.
2. Utforske etterspørsel og tidsvariasjon.
3. Utvikle og evaluere statistiske modeller.
4. Beregne risiko ved ulike kapasitetsnivåer.
5. Simulere scenarioer og formulere anbefalinger.

## Teknologi

- Python
- SQL
- Git
- Power BI, dersom relevant
